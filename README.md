# ⚡ AduHP - Platform Adu Spek & Benchmark HP Baru Indonesia

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Faduhp888%2Faduhp-web)

Aplikasi web modern untuk perbandingan spesifikasi dan performa smartphone **100% Baru (BNIB Segel Resmi Indonesia)**. Dilengkapi visualisasi benchmark **AnTuTu v10**, estimasi FPS gaming riil, dan filter rentang harga terlengkap.

---

## 🚀 Fitur Unggulan

1. **🔥 100% HP Baru (BNIB Resmi Indonesia)**:
   - Garansi resmi distributor nasional (TAM, SEIN, iBox, Carlcare, dll).
   - Bebas blokir IMEI, segel pabrik utuh.

2. **⚔️ Halaman Menu Khusus `/adu-hp`**:
   - Adu 3 smartphone sekaligus secara real-time.
   - Pilihan Match Derby Populer (Raja Flagship, Flagship Killer, Mid-Range Value, Entry Level, Duel Lintas Kelas).
   - Estimasi FPS Gaming (Mobile Legends, Free Fire, PUBG Mobile, Genshin Impact).
   - Perbandingan matriks hardware lengkap (Chipset, RAM/ROM, Layar, Kamera, Baterai & Charging).

3. **📊 Skor AnTuTu Benchmark v10 Menarik**:
   - Total Skor AnTuTu v10 dengan visual dynamic glow bar.
   - Breakdown performa: CPU, GPU, Memory, dan UX.
   - Klasemen ranking performa berdasarkan tier harga.

4. **💰 4 Kategori & Pilihan Harga Lengkap**:
   - **Rp 1 – 2 Jutaan**: Entry Level Value (POCO M6 Pro, Infinix Note 40, Redmi Note 13, itel S23+).
   - **Rp 2 – 4 Jutaan**: Mid-Range Sweet Spot (POCO X6 5G, Samsung Galaxy A25 5G, Realme 12+ 5G, Vivo V30e).
   - **Rp 4 – 8 Jutaan**: Flagship Killer & Upper Mid (Xiaomi 14T, POCO F6, Realme GT 6, Samsung Galaxy A55 5G).
   - **Rp 8 Juta+ (Ultra Flagship)**: The Absolute Best (Samsung Galaxy S24 Ultra, iPhone 16 Pro Max, Xiaomi 14 Ultra, Vivo X100 Pro).

5. **🛒 Integrasi Checkout WhatsApp & Toko Resmi**:
   - Tombol langsung terhubung ke WhatsApp Official Store dengan template pesan otomatis unit BNIB.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **UI Library**: [React 19](https://react.dev/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Styling**: Cyber Dark Aesthetic (Vanilla CSS Design System)
- **Deployment**: [Vercel](https://vercel.com/)

## 🚀 Cara Deploy ke Vercel

### Opsi 1: 1-Klik Deploy (Paling Mudah)
Klik tombol di bawah ini untuk deploy otomatis ke akun Vercel Anda:

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Faduhp888%2Faduhp-web)

### Opsi 2: Hubungkan via Dashboard Vercel
1. Buka [Vercel Dashboard](https://vercel.com/dashboard).
2. Klik **Add New...** > **Project**.
3. Pilih repository **`aduhp888/aduhp-web`** dari akun GitHub Anda.
4. Klik **Deploy** (Pengaturan Next.js akan terdeteksi otomatis tanpa perlu konfigurasi tambahan).
5. Setiap kali Anda melakukan `git push` ke branch `main`, Vercel akan otomatis melakukan build & deploy versi terbaru.

---

## 💻 Menjalankan di Lokal (Development)

```bash
# Clone repository
git clone https://github.com/aduhp888/aduhp-web.git

# Masuk ke folder proyek
cd aduhp-web

# Install dependencies
npm install

# Jalankan server development
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) di browser untuk melihat hasilnya.
